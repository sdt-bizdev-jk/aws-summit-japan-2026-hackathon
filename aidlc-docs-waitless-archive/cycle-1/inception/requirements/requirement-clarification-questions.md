## 整理: 確定した方針
- **対象サイト**: Claude.ai のみ
- **検知方法**: Claude.ai の DOM 変化監視 (ストリーミング状態など)
- **完了通知**: タブ自動切替 (娯楽タブ → AIタブ) で代用、別途のOS通知/バッジ/音は無し
- **娯楽タブ管理**: ユーザーがドメインを登録、登録されたタブが既に開いていれば切替/なければ新規で開く想定
- **動画自動再生**: 娯楽タブ切替時に動画を自動再生したい
- **保存**: `chrome.storage.local` のみ (端末内完結)
- **品質**: MVP (Chrome Web Store 申請を見据えた品質)
- **スタック**: Manifest V3 + 素の JS/HTML/CSS、ビルド不要
- **拡張ルール**: Security/PBT どちらも適用しない (PoC/MVP前提)

X) Other (please describe after [Answer]: tag below)
