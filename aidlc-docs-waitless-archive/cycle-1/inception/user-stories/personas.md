## P-01: タカシ

| 項目 | 内容 |
|------|------|
| 名前 | タカシ |
| 職業 | エンジニア (もしくは Claude.ai を業務 / 個人で日常的に使う知識労働者) |
| 利用環境 | デスクトップ Chrome 最新版、メイン端末 1台 (端末間同期なし) |
| 利用頻度 | Claude.ai を 1日数回 〜 数十回 (調査・コード生成・文章執筆など) |
| 技術リテラシー | 中〜高 (Chrome 拡張のインストール、設定UIの操作はできる) |

### モチベーション
- 出力待ちの「数十秒〜数分」が積み重なってしまうのを「もったいない」と感じている
- 動画視聴 (YouTube 等) や SNS など別のタブを開いて気晴らしすることがあるが、Claude.ai と娯楽タブを行き来するのが地味に手間
- 結局は画面を眺めて待ってしまい、待ち時間を有効活用しきれていない

### 痛み (Pain Points)
- 出力が始まったか分からず、待っているのか動いているのか判断に迷う
- 別タブを開いて娯楽を楽しんでも、Claude.ai の完了を見逃してしまうのが不安で集中できない
- 完了タイミングを知るために結局 Claude.ai のタブをチラチラ確認してしまう

### ゴール / 期待
- 待ちが発生したら自動で娯楽タブに飛んで、即座に楽しめる
- 出力が終わったら自動で Claude.ai タブに戻ってきて、シームレスに作業へ復帰できる
- セットアップは最小限。1度設定すればその後は意識せずに使える

### 行動特性
- 設定はシンプルに保ちたい派 (細かいトグルや一時停止機能は使わない、常時ON で OK)
- 自分の好きな YouTube プレイリストや SNS のドメインを登録するくらいの操作はいとわない
- 端末は基本 1台、ブラウザの同期機能には頼らない

### 端末/プライバシーの前提
- データは端末ローカルに留めたい (`chrome.storage.local` のみ)
- 外部サーバーへの送信や統計トラッキングは不要
