# WaitLess (Chrome 拡張機能)

生成AI (Claude.ai) の出力待ち時間を、登録した娯楽サイトへの自動切替で快適にする Chrome 拡張機能。動画・ゲーム・SNS・EC ショッピング・ストレッチ瞑想など、お好みのサイトを娯楽タブとして登録できます。

- Claude.ai のストリーミングが N秒以上 続いたら、登録された娯楽タブに自動切替
- 出力完了を検知したら Claude.ai タブに即時戻る
- すべての設定は端末ローカル (`chrome.storage.local`) に保存、外部送信なし

## 動作要件

- Chrome (Manifest V3 対応版、最新の安定版を推奨)
- Claude.ai のアカウント (本拡張は認証を扱いません)

## インストール (Unpacked ロード)

1. このリポジトリを clone する
2. Chrome で `chrome://extensions/` を開く
3. 右上の「デベロッパーモード」を ON
4. 「パッケージ化されていない拡張機能を読み込む」をクリック
5. このリポジトリの `extension/` ディレクトリを選択

## 初期設定

1. 拡張機能のツールバーアイコンをクリック (またはオプションページを直接開く)
2. **しきい値 (秒)** を設定 (デフォルト 5、範囲 1〜60)
3. **娯楽サイト** を 1件以上 登録 (詳細は次セクション参照)
4. 必要なら優先順位を ▲▼ で調整

## 対応する遷移先パターン

WaitLess は登録 URL に対して汎用的に動作します。代表的な利用パターンを以下に挙げます。あなたの好みのサイトを登録してください。

| カテゴリ | 用途 | サンプル ドメイン | サンプル URL |
|---------|------|-----------------|-------------|
| 🎬 **動画** | 動画視聴 (YouTube 等)。動画の自動再生試行あり、Claude.ai 完了時に一時停止して次サイクルで続きから再生 | `youtube.com` | `https://www.youtube.com/feed/subscriptions` |
| 🎮 **ゲーム** | 短時間の Web ゲームで気分転換 | `games.greggman.com` | `https://games.greggman.com/game/htmlbird/` |
| 🛒 **EC ショッピング** | EC サイトでウィッシュリスト確認、買い物 | `amazon.co.jp` | `https://www.amazon.co.jp/gp/your-account/order-history` |
| 💬 **SNS チャット** | SNS で短時間のフィード閲覧 / チャット | `x.com` | `https://x.com/home` |
| 🧘 **ストレッチ・瞑想** | 集中力維持のためのストレッチ/瞑想 (動画形式が手軽) | `youtube.com` | `https://www.youtube.com/results?search_query=10分+ストレッチ` |
| 📖 **読書 (内蔵)** | 拡張機能内蔵の読書ページで小説テキストを読み進める。クリックで既読範囲を青色化、スクロール+クリック位置を永続化 | `<拡張機能 ID>` | `chrome-extension://<ID>/reader/reader.html` |
| 🎬 **娯楽ポータル (内蔵)** | Netflix 風の一覧から動画 / 音楽 / EC / ゲーム / SNS / ニュース / 漫画 / 旅行など 12 ジャンル × 6 サイト = 72 カードを 1 クリックで遷移 (cycle-5 〜) | `<拡張機能 ID>` | `chrome-extension://<ID>/portal/portal.html` |

### 補足

- **登録は domain と URL のペア** で、特別なカテゴリ指定は不要です。動画系のサイトでは `<video>` タグへの自動再生試行が動きますが、動画がないページではブラウザに何も影響しません
- **動画自動再生はベストエフォート**: ブラウザのオートプレイポリシーで失敗することがあります (この場合は静かに諦めます)
- **ドメインが同じ場合は 1 件のみ登録可能**: 例えば動画用とストレッチ用で `youtube.com` を 2 つ登録することはできません (URL を片方に決めて登録してください)

## 内蔵の読書ページについて (cycle-3 〜)

WaitLess には拡張機能内蔵の読書ページ (`chrome-extension://<拡張機能 ID>/reader/reader.html`) が含まれています。AI 待ち時間に小説テキストを読み進めるシンプルな機能です。

### 登録方法

1. 拡張機能をロードした状態で Options Page を開く
2. 空状態案内の「📖 読書 (内蔵)」項目に **拡張機能 ID** と **URL** が動的に表示されます (拡張機能ロードごとに ID は変わる可能性があります)
3. 表示された ID を「ドメイン」欄に、表示された URL を「URL」欄にコピペで登録

### 動作

- 待ち時間に登録された読書ページタブが開きます (既存タブがあればアクティブ化)
- 灰色のテキストをクリックすると、ページ先頭からクリック位置までが **青色** に変わります
- 既に青色化されている範囲より前をクリックすれば、その位置まで戻る (双方向クリック)
- AI 出力完了で AI タブに戻ります、その時点でのスクロール位置とクリック位置が記録されます
- 次回読書ページが開いたとき、保存されている状態を復元 (青色化 + スクロール) します

### テキストについて

- 初期状態では拡張機能に **オリジナルの短いサンプルテキスト** が組み込まれています
- 別のテキストに差し替えたい場合は `extension/reader/novel.txt` を任意の UTF-8 プレーンテキストに上書き保存してください (青空文庫等のパブリックドメイン作品からのテキストを推奨)
- 拡張機能をリロードすれば反映されます。差し替え後は既読位置がずれる可能性があるため、必要に応じて Options Page から登録を作り直してください

### 制約

- 同時に管理できる小説は 1 編のみ (cycle-3 の MVP)
- UI のカスタマイズ (フォント / 文字サイズ / テーマ) はなし
- 端末間同期はなし (`chrome.storage.local` に閉じる、プライバシー方針に整合)

## 内蔵の娯楽ポータルページについて (cycle-5 〜)

WaitLess には拡張機能内蔵の娯楽ポータルページ (`chrome-extension://<拡張機能 ID>/portal/portal.html`) が含まれています。Netflix 風のカード一覧から、AI 待ち時間に好きな娯楽サイトへ 1 クリックで遷移できる入口ページです。

### 登録方法

1. 拡張機能をロードした状態で Options Page を開く
2. 空状態案内の「🎬 娯楽ポータル (内蔵)」項目に **拡張機能 ID** と **URL** が動的に表示されます
3. 「このポータルを登録する」ボタンをクリックすると、現在の拡張機能 ID + URL が `sites` に登録されます
4. 手動で登録したい場合は、表示された ID を「ドメイン」欄に、URL を「URL」欄にコピペでも可

### 収録ジャンル (12 種)

🎬 動画視聴 / 🎵 音楽 / 🛒 EC ショッピング / 🎮 ゲーム / 💬 SNS / 📰 ニュース /
📖 読書 / 📚 漫画 / ⚽ スポーツ / 🍳 料理 / ✈️ 旅行 / 🧘 リラックス

各ジャンルに 6 サイト、計 72 カード。クリックすると **同タブで** その公式トップに遷移します。

### 動作

- 待ち時間にポータルページタブが開きます (`sites` 登録すれば cycle-1 のタブ探索フロー Pass 1〜3 で動作)
- ジャンル行は **横スクロール** 可能 (マウスホイール + Shift で水平スクロール、または直接ドラッグ)
- カードをホバーすると拡大 + 影が強調されます
- カードのクリックは `<a href>` のデフォルト動作 (同タブ遷移)

### カスタマイズ

カードの追加・削除・並び替えは `extension/portal/portal_data.js` を直接編集してください (一覧データ 1 ファイルで完結)。サイト URL の変更も同様。スキーマ:

```js
window.PORTAL_DATA = [
  {
    genre: "動画視聴",
    emoji: "🎬",
    cards: [
      { name: "YouTube", url: "https://www.youtube.com/", emoji: "▶️" },
      // ...
    ],
  },
  // ...
];
```

### 制約

- カード画像は使わず絵文字のみ (バンドル軽量化方針)
- ユーザーがブラウザ UI からカードを編集する画面はなし (cycle-5 のスコープ外、`portal_data.js` 直接編集のみ)
- お気に入り / 履歴の保存なし

## IDE 連携 (cycle-4 〜、実験的)

cycle-4 から、Kiro IDE 用 VS Code 拡張機能 (`vscode-extension/`) との連携機能が追加されました。Kiro 上で AI 応答を待つ間、本 Chrome 拡張に登録された娯楽サイトを自動で開き、AI 完了で動画一時停止 + Kiro ウィンドウ最前面化を行います。

### 仕組み

- ローカルの WebSocket (`ws://127.0.0.1:39472`) で双方向通信 (外部公開なし)
- Kiro 側拡張機能がサーバー、Chrome 拡張 (本 Service Worker) がクライアント
- Service Worker 起動時に自動で接続を試行、失敗時は指数バックオフで永続再試行 (1秒 → 2秒 → ... → 30秒で頭打ち)
- メッセージタイプ: `GET_SITES` / `FIND_OR_OPEN_TAB` / `PAUSE_MEDIA` / `PING`-`PONG`

### 設定

Options Page の「🔌 IDE 連携 (cycle-4 実験的)」セクションで ON/OFF を切り替えられます。デフォルトは **ON**。OFF にすると WebSocket 接続を切断し、再接続を停止します。

cycle-3 までの既存機能 (Claude.ai 監視 → 自動切替) は IDE 連携の ON/OFF にかかわらず引き続き動作します (NFR-27 後方互換性)。

### 利用条件

- Kiro IDE がインストールされていること
- `vscode-extension/` の WaitLess IDE 拡張機能が起動していること
- macOS 環境 (osascript 前提)

### 制約

- VS Code 拡張機能側でポート 39472 が listen できていない場合 (別プロセスが使用中等) は接続できず、IDE 連携機能のみ無効化される (Chrome 拡張全体は動作継続)
- 同時に複数の Kiro / VS Code ウィンドウを開いている場合の挙動は未保証 (1 ウィンドウ前提)

## 動作の概要

- Claude.ai を開いて応答を待っているとき、応答ストリーミングが **しきい値秒** 以上 続くと、登録の上位から「現在の Chrome ウィンドウで同ドメインのタブが開いているか」を確認します
  - 開いていればそのタブに切替 (登録 URL と完全一致なら続きから再生、ドメインのみ一致なら登録 URL に navigate)
  - どこにも開いていなければ、優先順位 1位 の URL で新規タブを開く
- 動画ありのページではあれば自動再生を試みます
- Claude.ai の応答が完了したと検知すると、自動で Claude.ai タブに戻ります
- 動画ありのページでは、戻る前に動画を一時停止します (次サイクルで続きから再生されます)

## 既知の制限事項

- **Claude.ai の DOM 変更**: Claude.ai の UI が変わるとストリーミング/完了の検知が壊れる可能性があります。修正版のリリースが必要になります
- **動画自動再生**: ブラウザのオートプレイポリシー (ユーザー操作なしの再生制限) で失敗することがあります
- **複数ウィンドウ**: 切替先タブの探索は **現在のフォーカスウィンドウ内のみ** です。別ウィンドウに開いている娯楽タブはヒットしません
- **Manifest V3 の Service Worker**: アイドル時にアンロードされます (Chrome の仕様)。状態は session ストレージに保存しているため再起動に耐えますが、稀に挙動が遅延することがあります

## アンチスコープ (持たない機能)

- 統計/累計時間の記録 (どれだけ娯楽したか等)
- Claude.ai 以外のAIサービス対応 (ChatGPT, Gemini 等)
- ON/OFFトグルや一時停止機能 (常時ON)
- 端末間同期 (`chrome.storage.sync` 不使用)
- OS通知 / バッジ / 効果音 (タブ自動切替を以て完了通知とします)
- ツールバーアイコンのポップアップUI (設定はオプションページのみ)
- 多言語対応 (日本語のみ)
- カテゴリ (タイプ) 別の振る舞い分岐: サイトはすべて統一的に扱います。動画自動再生のような付随動作は、当該ページに `<video>` がある場合に限り副作用なしで実行されます
- 読書ページの複数小説管理 (cycle-3 では 1 編のみ)
- 読書ページの UI カスタマイズ (フォント / 文字サイズ / テーマ等は固定)
- 読書ページの既読位置の端末間同期 (`chrome.storage.local` に閉じる)

## アイコンについて

`assets/icons/` 配下の PNG は **1x1 透過のプレースホルダ** です。Chrome Web Store 申請時には必要に応じて 16x16 / 48x48 / 128x128 の本物の PNG に差し替えてください。

## プライバシー

- すべてのデータ (登録サイト一覧、しきい値) は端末内の `chrome.storage.local` のみに保存されます
- 外部サーバーや外部APIへの送信は一切行いません
- DevTools の Network タブで通信が発生していないことを確認できます

## 開発メモ

- 素のJavaScript / HTML / CSS のみで構成 (TypeScript / バンドラ / npm 依存ゼロ)
- ビルド不要、`extension/` ディレクトリをそのまま Unpacked ロードできます
- ファイル構成:
  - `manifest.json` ... Manifest V3 設定
  - `service_worker.js` ... バックグラウンド (Service Worker) のエントリ
  - `sw/*.js` ... Service Worker 内モジュール (5つ)
  - `content/*.js` ... Content Script (Claude.ai および娯楽タブに動的注入)
  - `options/*` ... オプションページ (HTML/CSS/JS)
  - `assets/icons/*` ... 拡張機能アイコン
