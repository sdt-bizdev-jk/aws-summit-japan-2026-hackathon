# ペルソナ定義

## 概要
利用段階に基づく3ペルソナ。「三日坊主を繰り返す人」という共通属性を持ちつつ、サービスとの関わり方が異なる。

※ v1から変更なし。アーキテクチャ変更（React Native化等）はユーザー体験に影響しないため、ペルソナ定義はそのまま引き継ぐ。

---

## Persona 1: はじめてのタビビト（初回ユーザー）

| 項目 | 内容 |
|---|---|
| **名前** | ユキ |
| **属性** | 何かを始めてはやめてを繰り返している。自己嫌悪がある |
| **動機** | 「また続かなかった」という罪悪感を減らしたい |
| **行動パターン** | 新しいことを始める→数日で飽きる→自分を責める→しばらく何もしない→また始める |
| **サービスへの期待** | やめたことを責められない場所。始めるハードルが低いこと |
| **利用段階** | 初めて旅に出る〜最初の途中下車まで |
| **成功体験** | 初めての途中下車で「道中で見た景色」が言語化され、「ゼロじゃなかった」と感じる |

### ユキの典型シナリオ
1. SNSで見かけて「やめてもいいアプリ」に興味を持つ
2. 30秒で「ランニング」の旅に出る
3. 3日後にフェードアウト
4. 途中下車確認が来て「降りる」を選ぶ
5. AIが「自分のペースで走れることを確認した」と景色を提示
6. 「あ、確かにそうだ」と感じる

---

## Persona 2: リピーター（複数回利用ユーザー）

| 項目 | 内容 |
|---|---|
| **名前** | ケンタ |
| **属性** | 3〜5回の途中下車を経験済み。サービスの仕組みを理解している |
| **動機** | 自分のパターンを知りたい。次に何をやったら面白いか気になる |
| **行動パターン** | 気軽に旅に出る→途中下車を恐れない→一覧を眺める→横断分析の結果に興味を持つ |
| **サービスへの期待** | 溜まった旅から見えるパターン。「次の旅先」の提案 |
| **利用段階** | 複数回の途中下車後〜横断分析の活用 |
| **成功体験** | 横断分析で「体を動かす系に何度も出かけてる」と気づき、提案された「散歩」を始める |

### ケンタの典型シナリオ
1. 筋トレ3日、ランニング2日、ヨガ1日で途中下車済み
2. 一覧画面で旅の数「6」を見て「結構やってるな」と思う
3. 横断分析を見る→「体を動かす方向に何度も出かけてますね」
4. 「散歩はどうですか？」と提案される
5. 「確かに一番ハードル低いな」と思い旅に出る

---

## Persona 3: ソーシャル観察者（他者の旅を見るユーザー）

| 項目 | 内容 |
|---|---|
| **名前** | ミサキ |
| **属性** | 自分も三日坊主だが、他の人の途中下車を見て安心感を得るタイプ |
| **動機** | 「自分だけじゃない」と確認したい。他の人がどんな旅をしているか気になる |
| **行動パターン** | タイムラインを眺める→共感する→自分も気軽に旅に出る |
| **サービスへの期待** | 匿名タイムラインで他者の途中下車が見えること。孤独感の解消 |
| **利用段階** | ソーシャル機能を活用しつつ、自分の旅も並行 |
| **成功体験** | 他の人が「ギター3日で降りた」のを見て「自分もピアノ2日で降りたけど、みんなそうなんだ」と安心する |

### ミサキの典型シナリオ
1. タイムラインで「誰かが早起き5日で途中下車」を見る
2. 「自分も早起き3日だったな」と共感
3. 安心感を得て、自分も「自炊」の旅に出てみる
4. 2日で途中下車しても罪悪感がない

---

## ペルソナ間の関係

```
ユキ（初回）──[旅を重ねる]──→ ケンタ（リピーター）
                                    │
ミサキ（ソーシャル観察者）←─[タイムラインで他者を見る]─┘
     │
     └──[自分も旅に出る]──→ ユキ/ケンタの体験へ
```

全ペルソナに共通: 三日坊主を繰り返す人。違いは「サービスとの関わり方の深さ」と「何に価値を感じるか」。
