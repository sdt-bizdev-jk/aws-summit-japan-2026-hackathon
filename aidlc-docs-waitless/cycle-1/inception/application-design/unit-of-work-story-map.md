```
[U1 のストーリー実行順 = ユーザーから見た体験]

  US-06  --(初回利用)-->  US-05  --(設定登録)-->

  US-01  ⇄  US-02  ⇄  US-03  ⇄  US-04

```

US-06 と US-05 は最初のセットアップ。US-01 〜 04 が日常的に繰り返されるループ。
