## 1. プロジェクト基本情報 (要件ドキュメントに記載予定)

| 項目 | 内容 |
|------|------|
| プロジェクト名 | WaitLess |
| 由来 | "Wait" + "Less" (待ち時間を減らす) |
| 種別 | Chrome 拡張機能 (Manifest V3) |
| 対象環境 | デスクトップ Chrome ブラウザ |
| 想定ユーザー | Claude.ai を業務/個人で頻繁に使い、出力待ちの数十秒〜数分を有効活用したい人 |
| 完成度ゴール | MVP (Chrome Web Store 申請を見据えた品質) |
| 開発スコープ (本サイクル) | Inception 完了後、Construction で 1ユニット分のコード生成まで |

## 2. 中核体験フロー (要件ドキュメントに記載予定)

```
[1] ユーザーが Claude.ai でプロンプトを送信
        ↓
[2] WaitLess が Claude.ai のストリーミング応答を監視
        ↓
[3] ストリーミングが N秒以上 続いていることを検知 (短い応答は無視)
        ↓
[4] 登録された娯楽サイトの優先順位リストを参照
        ├─ 上位から「既に該当タブが開いているか」を確認
        ├─ 開いている → そのタブへ切替
        └─ 開いていない → 登録された動画URLで新規タブを開いて切替
        ↓
[5] ユーザーは娯楽タブで動画視聴等を楽しむ
        ↓
[6] WaitLess は Claude.ai タブの DOM を監視し続け、出力完了を検知
        ↓
[7] 即座に Claude.ai タブへ強制切替 (= 完了通知)
```

## 3. 解釈の明示 (CQ2/CQ3 整合性確認)

CQ2 (動画自動再生 = 毎回 URL を開く) と CQ3 (既に開いているタブを優先) を整合的に解釈すると以下になります。要件ドキュメントもこの解釈で記述する想定です。**この解釈で問題ないかご確認ください**:

> **解釈**: 優先順位リストの上位から順に「同じURL (または同一ドメイン) のタブが既に開いているか」を確認する。開いていればそのタブへ切替えて動画再生を促す (停止していれば再生再開)。どこにも開いていなければ、登録された動画URLで新規タブを開いて切替える。

別解釈 (例: 「常に新規タブで開く」「既に開いている場合は閉じてから新規で開く」) を希望される場合は、プラン承認時に教えてください。

## 4. 機能要件 (FR) — 要件ドキュメントに記載予定の見出し

| ID | 概要 |
|----|------|
| FR-01 | Claude.ai タブの自動検出 (URL マッチング) |
| FR-02 | Claude.ai 応答ストリーミング状態の DOM 監視 |
| FR-03 | ストリーミング継続 N秒判定によるトリガー発火 |
| FR-04 | 娯楽サイト登録 (ドメイン + 自動再生URL のペア、優先順位付き) |
| FR-05 | 既存娯楽タブの探索と優先順位ベースの選択 |
| FR-06 | 娯楽タブへの自動切替 (既存 or 新規作成) |
| FR-07 | Claude.ai 応答完了の DOM 検知 |
| FR-08 | Claude.ai タブへの自動戻り (即時) |
| FR-09 | オプションページでの設定UI (登録ドメイン/URL/優先順位の管理) |
| FR-10 | 設定の `chrome.storage.local` 永続化 |
| FR-11 | N秒判定のしきい値 (デフォルト値 + ユーザー変更可否は要件で確定) |

## 5. 非機能要件 (NFR) — 要件ドキュメントに記載予定の見出し

| ID | 概要 |
|----|------|
| NFR-01 | Manifest V3 準拠 |
| NFR-02 | 端末ローカル完結 (外部送信なし、`chrome.storage.local` のみ) |
| NFR-03 | Chrome Web Store 申請可能な品質 (権限最小化、明確な説明) |
| NFR-04 | ビルド不要 (素の JS/HTML/CSS、追加ツールチェーン無し) |
| NFR-05 | 監視によるパフォーマンス影響を最小限に (DOM observer の対象限定) |
| NFR-06 | 日本語UI (今回は単一言語) |

## 6. 絶対にやらないこと (アンチスコープ)

- 待ち時間/娯楽時間の統計・ログ機能 (CQ8=A)
- Claude.ai 以外のAIサイト対応 (将来の設計余地も今回は持たない)
- 端末間同期 (`chrome.storage.sync` 不使用)
- 外部サーバー連携 (AI APIへの直接アクセスや、外部分析基盤への送信)
- OS通知/バッジ/効果音 (タブ自動切替を以て完了通知とする)
- ON/OFFトグル (常時ON、ユーザーが操作で止める仕組みは作らない)
- ポップアップUIへの設定統合 (設定はオプションページのみ)

## 7. 用語定義 (要件ドキュメントに記載予定)

| 用語 | 意味 |
|------|------|
| AIタブ | Claude.ai を表示しているタブ |
| 娯楽タブ | ユーザーが登録したドメイン (動画/SNS等) のタブ |
| 待ち発生 | ストリーミングが N秒以上 続いている状態と判定された瞬間 |
| 完了検知 | Claude.ai のストリーミングが終わったことを DOM 変化で検知した瞬間 |
| トリガー | 待ち発生 → 娯楽タブ自動切替 / 完了検知 → AIタブ自動切替 のいずれか |
